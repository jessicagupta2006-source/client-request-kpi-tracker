# Client Request KPI Tracker

An Excel-based analytics project designed to track client service requests and monitor key performance indicators (KPIs).

## Project Overview

This project analyzes client requests using Excel formulas, KPI calculations, and visual dashboards.

The tracker contains 20 sample client requests with information such as:

- Client Name
- Request Date
- Request Type
- Priority
- Status
- Assigned Team Member
- Resolution Time
- SLA (Service Level Agreement) Days
- Client Rating
- SLA Status

## Key KPIs

The dashboard calculates:

- Total Client Requests
- Resolved Requests
- Open Requests
- Average Client Rating
- SLA Compliance %
- Breached SLA Count

## Dashboard

The KPI dashboard includes:

- Request Status Overview
- SLA Compliance Overview
- KPI summary table
- Bar chart for request status
- Pie chart for SLA compliance

## Tools Used

- Microsoft Excel
- Google Sheets
- Excel formulas
- KPI analysis
- Data visualization
- Dashboard creation
